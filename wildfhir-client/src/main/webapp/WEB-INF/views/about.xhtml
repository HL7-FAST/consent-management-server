This is the FAST Consent IG Reference Implementation Test Client web application. The interfaces provide a means to:

  • FAST Consent Ops - Send valid FAST Consent IG operation requests using a small predefined set of test data (Patient, RelatedPerson)
    • Patient: Lara Miren; RelatedPersons: Robert Miren spouse, Fred Miren brother-in-law
    • Patient: Gerald Larin; RelatedPersons: Susan Larin spouse, Samuel Larin son
  • FHIR Interactions - Send valid FHIR read, history and search interactions to retrieve data on a Consent Management Server; additional interactions:
    • metadata - return a Consent Management Server CapabilityStatement
    • $validate - validate FAST Consent based resources for conformance (validation is supported by the underlying HL7 FHIR Core Library and pre-loaded FAST Consent IG and dependent IG validation packages)
  • Subscriptions - Create, manage and review Subscriptions against a Consent Management Server
    • Create (TBD) - define/create a new Subscription for a selected Consent on a Consent Management Server
    • Update (TBD) - update an existing Subscription for a selected Consent on a Consent Management Server
    • Activity (TBD) - list Subscription activity for this client
    • Manual - manually execute the Subscription Service for this RI
  • Admin - Administer defined Consent Management Servers and their (FHIR) base url value
    • Servers - manage the list of known Consent Management Servers
    • Reset Test Data - purge and re-load the predefined client resources; also, purge all server resources
