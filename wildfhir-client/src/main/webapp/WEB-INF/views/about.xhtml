This is the FAST Consent IG Reference Implementation Test Client web application. (Built on the AEGIS WildFHIR Community Edition Reference Implementation Test Client web application.) The interfaces provide the following functionality:

  • FAST Consent - Send valid FAST Consent IG operation requests using a small predefined set of test data (Patient, RelatedPerson)
      Patients:
    • Lara Miren; RelatedPersons: Robert Miren spouse, Fred Miren brother-in-law
    • Gerald Larin; RelatedPersons: Susan Larin spouse, Samuel Larin son


    • $fileConsent - used to file a consent with a consent administration service
    • $revokeConsent - used to revoke a consent with a consent administration service
    • Create AuditEvent - used to record an AuditEvent disclosure based on a given consent for a given patient with a consent administration service
  • Subscriptions - Manage FAST Consent Subscriptions
    • Create - create a new Subscription resource based on the FASTConsentSubscriptionTopic on a consent administration service
    • Update - update an existing Subscription resource based on the FASTConsentSubscriptionTopic on a consent administration service
    • Process - manually execute the Subscription Service for the FAST Consent RI server
    • Handshake - manually send a Handshake Notification to a selected Subscription endpoint
  • Interactions - Send valid FHIR interactions to a selected FHIR server
    • read - return a FHIR resource instance by its resource id
    • vread - return a FHIR resource instance by its resource id and version id
    • history - return the FHIR history by global, resource type or resource instance
    • search - return FHIR search results for a resource type
    • create - send a FHIR resource to be created
    • update - send a FHIR resource to be updated
    • patch - send a JSON or XML patch and FHIR resource to be updated
    • metadata - return a selected server's CapabilityStatement
  • Operations - Send FHIR extended operations to a selected FHIR server
    • $convert - FHIR extended operation to convert JSON to/from XML
    • $everything - FHIR everything operation
    • $validate - validate FHIR resources (validation is supported by the underlying HL7 FHIR Core Library and pre-loaded FHIR R4 v4.0.1 validation packages)
  • Tools - WildFHIR Tools
    • FHIR Path - execute FHIR Path evaluations using the AEGIS WildFHIR extended operation '$fhirpath-evaluate
  • Admin - Administration functionality
    • Servers - manage the list of known FHIR Servers and their base url value
    • Reset Test Data - purge and re-load the predefined client resources; also, purge all server resources
