This is the FAST Consent IG Reference Implementation Test Client web application. The interfaces provide a means to:

  • FAST Consent Ops - Send valid FAST Consent IG operation requests using a small predefined set of test data (Patient, RelatedPerson)
  • FHIR Interactions - Send valid FHIR read and search interactions to retrieve data on a Consent Management Server
  • Subscriptions - Create, manage and review Subscriptions against a Consent Management Server
  • Admin - Administer defined Consent Management Servers and their (FHIR) base url value
